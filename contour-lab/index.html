動画

fpsは自動計測を試みます。ズレる場合は手入力で上書き（フレーム番号と書き出しの整合に効きます）。

シーン / カット

再生して色変化からカットを検出。タイムライン右クリックで手動追加/削除、Shift+←→でシーン移動。カット跨ぎは線を引き継ぎません。

ツール

雑にペンで描く→W（またはボタン）で、その線を近くの色エッジへ吸着します。1回のUndoでラフ線に戻せます。

領域選択（実験）

量子化で境界をはっきりさせ、ワンドで領域をクリック取込。選択中の色へ「追加」します（除去はオブジェクト消しゴム）。

前景（選択色）と背景を太ブラシで雑に塗る→自動で境界を推定→「確定」でマスク化。前景・背景の両方を塗ると精度が上がります（β：グラフカット/伝播は後日）。

色（マスク）

各色＝別マスク。名前欄はクリックで編集可。キャラを囲うと未割当の残りが自動で背景になります（P1では表示のみ）。

領域整形（選択色）

「内部の線を掃除」は塗りの内側に埋もれた線だけ消し、外側と穴（ドーナツ）の輪郭は残します。

参照・補助

フレーム引き継ぎ

空フレームへ移動すると前フレームの線をそのまま複製します（通常表示）。消しゴム/加筆で部分編集できます。

編集

プロジェクト

—

編集はブラウザ内(IndexedDB)に自動保存されます。書き出しは別PCへ移す用。

読み込み（下描き取込）

選択中の色へ取込みます。ファイル名の f00000 でフレーム対応（無ければ現在フレームから連番）。SAM等の下描きの受け口。

書き出し

ZIPは所有フレーム×色を白黒PNG＋manifest.json。本体用JSONは減色アプリへの取込用（RLE＋シーン情報、往復検証済み）。

操作

  • 左ドラッグ＝描画／消去
  • 右・中・Space+ドラッグ＝移動
  • ホイール＝カーソル中心ズーム
  • B ペン / E 消しゴム / S スナップ / W エッジ吸着 / G グリッド / D エッジ / Q 量子化 / A ワンド / X スクリブル
  • ← → フレーム送り / Shift+← → シーン移動（次/前シーンの先頭）/ F 全体 / 1 等倍
  • Ctrl+Z 戻す / Ctrl+Y やり直し

「動画を開く」から動画を読み込んでください。
